# To-Do List – Firebase

A simple web-based To-Do List application built with JavaScript and Firebase Firestore.

## Features

- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Display the total number of tasks
- Real-time data updates with Firestore
- Anonymous Firebase Authentication
- User-specific tasks with Firestore Security Rules

## Technologies

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Firebase Authentication
- Firebase Firestore
